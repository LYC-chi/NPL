# 基于年报文本挖掘的企业数字化转型测度研究

> 预演毕业论文模拟稿 · NLP测度构建方法课程作业
> 五步NLP测度流水线：**数据获取 → 文本预处理 → 中文分词 → 词典匹配 → 测度计算**，配套信度效度检验与回归分析，全流程可复现。

## 一键复现

```bash
pip install -r requirements.txt
python code/simulate_corpus.py   # 生成300份模拟年报文本（60家×2019-2023）
python code/pipeline.py          # 五步流水线 → output/panel_digital_transformation.csv
python code/analysis.py          # 描述统计 + 信度效度 + OLS回归
```

## 核心结果速览

| 检验 | 指标 | 结果 |
|---|---|---|
| 信度 | Cronbach's α（五维词频） | 0.706 |
| 信度 | 斯皮尔曼-布朗折半信度 | 0.757 |
| 同时效度 | DT 与研发强度相关 | r = 0.570*** |
| 已知组效度 | 高-低研发组 DT 均值差 | 0.383 |
| 回归 | Size / RD 对 DT | +0.169*** / +6.033*** |
| 回归 | R²（含年份/行业固定效应） | 0.837 |

主测度 `DT = ln(1+数字化关键词总词频)`；DT 均值由 2019 年 4.018 逐年升至 2023 年 4.435。

## 方法说明

- **词典**：人工智能 / 区块链 / 云计算 / 大数据 / 数字技术应用 五维度共 79 个关键词，参考吴非等（2021，《管理世界》）并扩充"大模型""生成式人工智能"等新词。
- **关键细节**：词典术语以高词频加入 jieba 自定义词表，保证"工业互联网"等多字术语整词匹配。
- **数据说明**：为保证结果完全可复现，语料为程序生成的模拟年报（生成逻辑内置"数字化叙述密度随研发强度、规模、时间变化"的结构）；五步流水线接口与真实语料完全一致，替换语料即可迁移。
